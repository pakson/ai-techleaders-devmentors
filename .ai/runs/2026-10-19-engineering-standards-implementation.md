## Decisions

- **No AppConfig service / paginate helper yet**: no consumer; deferred per the keep-it-simple rule (spec §6.6, §16).
- **`dbTry((em) => ...)`** instead of a thunk: the helper reads `Db` itself, so callers don't need `yield* Db` first.
- **`effectAction({ input, output }, handler)`** mirrors `effectRoute` and encodes output, as the spec's "does the same" implies. `effectRoute` got an optional success `status` (201 for creates).
- **Health now answers 500 (generic body) when the DB is down** instead of 503 with the raw driver message: it follows the single error mapper and stops leaking connection details.
- **Effect diagnostics via the CLI** (`effect-language-service diagnostics --strict`) in `typecheck`, not by patching `node_modules/typescript`.
- **`import/no-relative-packages`** for relative cross-package imports: a `no-restricted-imports` glob can't detect `../../../../db/...`.
- **Prettier ignores** Markdown (AGENTS.md block is regenerated by Next; tables), migrations (never edit applied ones) and shadcn-managed `components/` + `styles/`.
- **No User migration**: only the id generator changed; `mikro-orm migration:check` reported no diff.
